🎓 Edusity - University Website

Edusity is a modern university website that provides detailed information about the institution, including courses offered, infrastructure, student testimonials, and a contact form to connect with university management.

🚀 Features
✅ **Course Details** – Explore all programs offered by the university  
✅ **Infrastructure Showcase** – View the campus facilities and amenities  
✅ **Student Testimonials** – Read real experiences from students  
✅ **Contact Form** – Get in touch with university management  
✅ **Fully Responsive** – Works seamlessly on all devices  

🏗️ Tech Stack
  - Frontend: HTML, CSS, JavaScript, React.js  
  - Styling: Tailwind CSS

🛠️ Installation & Setup
  1️⃣ Clone the Repository
   - git clone https://github.com/Rishabh0059/Edusity.git
   - cd Edusity

  2️⃣ Install Dependencies
    - npm install

  3️⃣ Start the Application
    - npm start

  The app will be available at https://rishabh0059.github.io/Edusity/
